Crimson Image Metadata 2.0.0 — sources and licensing

maps and styles are included in the HTML. No API keys or live tiles are used.

TEST IMAGES AND RESULTS
The tiny color images in tests/fixtures are synthetic, created by
tests/generate_fixtures.py with Pillow and deliberately chosen GPS values.
They are parser test inputs, not user photographs or location evidence.
Runtime coordinates come only from validated embedded metadata in the image
the user selects. No fixed example location is used when GPS is missing.
SHA-256 and analysis logs are calculated during analysis; no model, packet
capture, identity matching or visual geolocation system is included.
